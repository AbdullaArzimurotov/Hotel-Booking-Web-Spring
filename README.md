# Веб-приложение «Гостиница»

Курсовая работа по дисциплине **«Разработка корпоративных приложений»**.

- **Автор:** Арзимуротов А.М.
- **Группа:** ПИН-123.
- **Тема:** веб-приложение для управления гостиницей с использованием Spring.

## Назначение проекта

Система предназначена для автоматизации работы одной гостиницы: учета номерного фонда, бронирования, заселения, продления проживания, выезда, уборки и управленческой отчетности.

Предусмотрены пять ролей: администратор, сотрудник службы приема и размещения, гость, сотрудник службы уборки и руководитель.

## Планируемые технологии

Java 21, Spring Boot 3.x, Spring MVC, Spring Data JPA, Spring Security, PostgreSQL, Thymeleaf, Bootstrap и Maven. Проверка бизнес-логики предусматривает JUnit 5 и Mockito.

Технологические требования описаны в [разделе анализа](docs/01-analysis/README.md#133-нефункциональные-и-технологические-требования). Инструкции по сборке и запуску будут добавлены вместе с реализацией.

## Организация работы

Документация размещается в `docs/`, каждый этап имеет собственный каталог. Названия каталогов закреплены в [оглавлении документации](docs/README.md) и сохраняются при добавлении следующих частей.

Каждый этап выполняется в отдельной ветке. Изменения предлагаются к проверке через запрос на включение и объединяются с `main` после проверки преподавателем.

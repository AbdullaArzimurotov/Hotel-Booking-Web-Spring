## Среда и выполненные действия

Проверка выполнена 30.10.2026 на PostgreSQL 18.4 из Postgres.app. Рабочая база — `hotel_booking_web`; каждый автоматизированный запуск использовал отдельную одноразовую базу со случайным суффиксом. Проверены начальная установка, повторная установка, ограничения и конкурентные запросы.

```sh
python3 database/tests/run_tests.py
```

## Результаты

| Группа | Фактический результат |
|---|---|
| Схема и роли | Созданы 10 таблиц и 5 ролей |
| Поля, ссылки, уникальность | Неверные FK и обязательные значения отклонены; email без учета регистра и номер комнаты уникальны |
| Даты и вместимость | Неверный интервал, прошлый заезд, переполнение и бронь заблокированного номера отклонены |
| Пересечения | Пересекающийся заказ отклонен с `23P01`, соседние интервалы разрешены |
| Снимок тарифа | Подставленная цена заменена действующим тарифом; изменение справочника не пересчитало бронь |
| Изменение данных | Конфликтующее продление и уменьшение вместимости отклонены; исходный срок сохранен |
| Проживание | Нельзя заселить в грязный или заблокированный номер, подменить номер или повторить активное проживание |
| Просроченный выезд | Поиск и создание нового заказа учитывают фактическую занятость |
| Выезд и уборка | Созданы завершение и одно задание; повтор не дублирует его; уборка не снимает ремонт |
| Уведомления | События подтверждения и отмены создаются; повтор без изменений не добавляет письмо; SENT требует времени |
| Расчеты | Три ночи по 5 000 рублей дают 15 000; с демонстрационным минимальным начислением 4 000 отчет дает 19 000; выбор двух ночей дает 10 000 |
| Загрузка | Два проживания по три ночи дают 6 номеро-ночей; при нулевой емкости нет деления на ноль |
| Транзакционный откат | Сравнение JSON-представления всех исходных строк до и после тестов совпало; календарная функция восстановлена |
| Повтор установки | Точные значения исходных строк, включая хеши и даты, не изменились |
| Две одновременные транзакции | Первая записала бронь, вторая после ожидания получила `23P01`; в базе остался один заказ |

**Итог: 51 регрессионная проверка пройдена; повтор установки и конкурентный сценарий пройдены.**

Все строки регрессионного набора откатились. Для проверки просрочки календарь временно моделировался внутри транзакции одноразовой базы, после чего исходное определение функции было восстановлено. Конкурентный сценарий подтверждает COMMIT первой транзакции, а не только последовательные INSERT. Одноразовая база удалена после завершения процесса.
